# v0 目标功能设计

> 本文定义新平台 v0 的功能边界。v0 是可用 MVP，不是完整企业平台。首版必须能完成知识接入、知识构建、RAG 对话、受控 ReAct 智能体、React Flow 可视化工作流、基础权限、审计和最小管理员后台。

## 1. v0 功能定位

v0 平台面向三类使用者：

| 使用者 | 定位 | v0 能力 |
| --- | --- | --- |
| 个人用户 | 个人空间内使用知识库和智能体能力 | 个人知识库、RAG 对话、受控 ReAct 智能体、工作流运行 |
| 租户用户 | 企业租户内协作使用知识库和工作流 | 租户知识库、成员邀请、知识库权限、RAG 对话、智能体和工作流 |
| 平台管理员 | 管理平台基础运行 | 用户、租户、任务、审计、健康检查、外部观测链接 |

v0 不发布公开 Open API/SDK，不建设完整 MCP/第三方插件市场，不建设完整系统运维 Web 端。

## 2. v0 功能域

| 功能域 | v0 目标 | 主要数据 |
| --- | --- | --- |
| 账号与会话 | 内置账号登录、会话、邀请、禁用用户 | 用户、会话、邀请 |
| 租户与空间 | 个人空间、企业租户、租户成员、最小角色 | 租户、成员、角色 |
| RBAC 与资源权限 | 最小 RBAC + 知识库级权限 | 角色、权限、知识库授权 |
| 知识库 | 文件/网页接入、解析、切片、构建、版本发布 | 文件、知识库、文档、切片、索引版本 |
| RAG 对话 | 授权知识库检索、生成、来源引用、反馈 | 会话、消息、引用、反馈 |
| ReAct 智能体 | 受控 ReAct 推理、受控 Action、运行日志 | 智能体定义、发布版本、运行实例 |
| 可视化工作流 | React Flow 画布、Workflow DSL、发布版本、Temporal 执行 | 工作流草稿、版本、运行实例、节点日志 |
| 内置受控工具 | LLM、RAG Retrieve、HTTP Request、Human Approval 等 | 工具定义、调用记录 |
| 最小管理员后台 | 用户、租户、任务、审计、健康和外部观测链接 | 审计、任务索引、健康状态 |

## 3. 账号、租户与权限

### 3.1 账号体系

v0 使用内置账号体系：

- 邮箱/用户名 + 密码登录。
- Session 使用 HttpOnly Secure Cookie。
- 支持退出登录、会话过期、禁用用户。
- 支持租户成员邀请。
- 预留 OIDC/SSO 扩展接口，但不交付企业 SSO、SAML、LDAP、MFA。

### 3.2 最小租户骨架

v0 企业版只保留最小租户骨架：

- 租户。
- 租户管理员。
- 租户成员。
- 知识库级权限。
- 基础审计。

v0 不做部门、岗位、复杂角色矩阵、插件审批、企业审计高级查询和配额报表。

### 3.3 权限模型

v0 使用最小 RBAC + 知识库级资源权限：

| 角色 | 能力 |
| --- | --- |
| 平台管理员 | 管理全局用户、租户、系统任务和最小后台 |
| 租户管理员 | 管理本租户成员、知识库、工作流和智能体配置 |
| 租户成员 | 使用被授权知识库、RAG 对话、智能体和工作流 |
| 个人用户 | 管理自己的个人空间资源 |

知识库权限：

- `owner`
- `admin`
- `editor`
- `viewer`

文档和切片继承知识库权限。v0 不做文档级、字段级、部门级、标签级 ABAC。

## 4. 知识库功能

### 4.1 接入范围

v0 支持以下知识材料：

- PDF
- Markdown
- TXT
- DOCX
- CSV
- XLSX
- HTML
- 单 URL 网页抓取
- PPTX

v0 不做图片 OCR、音视频转写、网页递归爬取、登录态网页抓取、JS 渲染页面抓取和反爬绕过。

### 4.2 网页抓取边界

v0 只做单 URL HTML 抓取：

- 用户提交单个 URL。
- 服务端检查并遵守 robots.txt。
- 服务端拉取 HTML，限制超时、最大响应大小、content-type 和重定向次数。
- 提取标题、正文、链接、发布时间等基础元数据。
- 记录来源 URL 和抓取时间。
- 支持手动重新抓取。

v0 不做 sitemap 批量导入、站点级爬虫、定时自动抓取、表单提交抓取。

### 4.3 表格材料边界

v0 表格只作为知识库检索材料，不做结构化数据分析：

- 支持 CSV、XLSX。
- 每个 sheet 转成带元数据的文本切片或 Markdown table。
- 保留文件名、sheet 名、行列范围、表头、单元格文本。
- 公式只读取计算后的展示值，不执行公式。
- 不做透视表、图表语义解析、跨表 join、SQL 查询、数值分析和 BI 报表。
- 设置最大文件大小、最大行数、最大列数和切片策略。

### 4.4 构建流程

知识构建由 Temporal 调度 Python AI Worker 执行：

```text
上传/抓取 -> 校验 -> 对象存储落盘 -> 解析 -> 清洗 -> 切片
-> Embedding -> 写入 Elasticsearch -> 验证 -> alias 发布
```

要求：

- 原始文件和解析中间产物进入 S3 兼容对象存储。
- PostgreSQL 保存元数据、任务状态、权限主数据和索引版本。
- Elasticsearch 保存检索切片和 embedding。
- 构建任务支持状态查询、失败重试、取消和重新构建。
- 每次发布生成索引版本，支持 alias 切换。

## 5. RAG 对话

v0 RAG 对话必须支持：

- 选择一个或多个授权知识库。
- Elasticsearch 关键词召回 + 向量召回。
- 权限过滤作为 Elasticsearch query/filter 下推。
- 上下文裁剪。
- LLM 生成回答。
- 返回来源引用。
- 多轮会话。
- 用户反馈。
- 审计记录和 TraceId。

RAG 不允许返回用户无权访问的文档细节。召回后可以二次校验权限，但不能只依赖召回后过滤。

## 6. ReAct 智能体

v0 包含基于 ReAct 的受控智能体，但不是开放工具执行平台。

### 6.1 智能体定义

智能体定义包含：

- 名称、描述。
- 系统 Prompt。
- 绑定知识库范围。
- 可用 Action 列表。
- `max_steps`。
- 单步超时、总超时。
- Token 预算。
- 失败停止策略。

智能体配置使用草稿 + 发布版本模型。运行实例必须绑定发布版本。

### 6.2 Action 边界

v0 ReAct 只允许：

- RAG Retrieve
- LLM
- HTTP Request
- Final Answer

HTTP Request 必须满足：

- 域名 allowlist。
- 参数 schema。
- 响应大小限制。
- 超时限制。
- 调用审计。
- 高风险请求进入 Human Approval。

v0 不允许 ReAct 执行任意代码、数据库查询、本地命令、写文件、操作系统资源或用户自定义 MCP Server。

## 7. 可视化工作流

### 7.1 画布

v0 使用 React Flow：

- 支持节点拖拽、连线、缩放、选择。
- 平台定义节点 schema 和校验规则。
- 后端保存平台自定义 Workflow DSL。
- 后端执行只认 DSL，不依赖 React Flow 内部 JSON。

v0 不做多人实时协作编辑。草稿同一时间只允许一个编辑者获得编辑锁，保存使用乐观锁。

### 7.2 版本模型

- 草稿可编辑。
- 发布后生成不可变版本。
- 运行实例绑定发布版本。
- 修改草稿不影响历史运行。
- 支持停用版本。
- 执行历史记录节点输入/输出摘要、状态、耗时、错误和 TraceId。

### 7.3 节点类型

v0 只支持 8 类节点：

| 节点 | 能力 |
| --- | --- |
| Start | 输入参数和启动上下文 |
| End | 输出结果 |
| LLM | 调用平台级主 LLM |
| RAG Retrieve | 授权知识库检索 |
| ReAct Agent | 执行受控 ReAct 智能体 |
| HTTP Request | 受 allowlist 和 schema 限制的 HTTP 调用 |
| Condition | 条件判断 |
| Human Approval | 人工确认 |

v0 不做循环、并行分支、子工作流、自定义代码、数据库查询、MCP 工具节点和定时触发器。

## 8. 模型与存储

### 8.1 模型

- v0 抽象模型适配层。
- 首版只接一个主 LLM 和一个 embedding 模型。
- 重排模型可选，没有就使用规则重排。
- 模型密钥由平台级配置提供，不支持租户自带 key。
- 记录 Token、耗时、错误码和调用量，不记录敏感 prompt 明文。

### 8.2 对象存储

- v0 使用 S3 兼容对象存储。
- Docker Compose 默认 MinIO。
- 生产可切到 S3/OSS/COS。
- 原始文件、解析中间产物、导出结果放对象存储。
- PostgreSQL 只保存元数据。
- 下载使用短期签名 URL 或后端代理。

## 9. 最小管理员后台

v0 不做完整系统运维 Web，只做最小管理员后台：

- 用户列表和禁用用户。
- 租户列表和租户状态。
- 知识库和构建任务列表。
- Temporal workflow 查询入口或链接。
- 任务失败重试/取消。
- 基础审计查询。
- 服务健康页。
- Grafana/Tempo/Temporal UI 等外部观测链接。

v0 不做 Kubernetes 资源治理、Patroni 操作、告警路由管理、发布回滚页面。

## 10. v1+ 后置能力

以下能力不进入 v0 验收：

- 公开 Open API/SDK。
- 开发者应用、签名协议、防重放和多语言 SDK。
- 完整 MCP/第三方插件市场。
- 用户自定义 MCP Server、任意脚本工具。
- 完整运维控制台。
- Kubernetes HPA/PDB/灰度发布治理。
- PostgreSQL Patroni/同步复制/多从 HA。
- 企业 SSO/OIDC/MFA。
- 复杂 ABAC、部门/岗位/字段级权限。
- 多模型供应商路由、BYOK 和成本优化。
